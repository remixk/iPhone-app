🔄 Comment ces données restent à jour

Ce site n'interroge pas d'API de prix en temps réel : il n'existe pas de flux public fiable de prix d'installation solaire en France. Les chiffres proviennent d'une agrégation manuelle de sources spécialisées, horodatée ci-dessous.

  • Toutes les fourchettes vivent dans data/prices.json, séparé du code de la page.
  • La date affichée en haut de page (—) correspond à la dernière relecture des sources.
  • Pour rafraîchir le site : relire les sources ci-dessous, mettre à jour data/prices.json, puis redéployer — aucune autre modification n'est nécessaire.
